Computer Science Course Progression

7 semesters required for DTE CS Distinction Placement exam for students with substantial prior experience to start in Tier 2

Start here

Tier 1 — entry courses

Recommended

Intro to Programming1 semester

  • Make art, animation, and interactive projects with code
  • Covers about 70% of an AP course, with plenty of rigor
  • Highly collaborative; no experience needed

AP Computer Science PrinciplesFull year

  • Programming in Python, plus data, algorithms, and how computers work
  • Hands-on problem solving across a full year
  • No experience needed; open to 9th graders who took Algebra I in 8th grade

Standalone offering — any year

New

AP CybersecurityFull year

  • Find the weak spots in networks, devices, and data before an attacker does
  • Analyze risk, mitigate risk, detect attacks
  • Option to earn an employer-endorsed credential alongside the AP exam
  • Aligned with CompTIA Security+ and Cisco CCST
  • No coding experience required

A complete experience on its own, open to any student in any year. Counts toward the 7-semester DTE distinction. See the course highlights sheet for how it combines with the programming sequence.

Tier 2 — optional

Applied Machine Learning1 semester

  • Requires: Intro to Programming or AP CSP, and Algebra II
  • Collect and clean your own data, then see how much it changes what your model predicts
  • Test your model until it breaks, then work out why
  • Ends with a unit running local models in the lab

AP Computer Science AFull year

  • Requires: Intro to Programming or AP CSP
  • Object-oriented design in Java: classes, arrays, and recursion
  • Design, write, and debug full applications from the ground up
  • The closest match to a first-year college CS course

Tier 2 is optional — students can go straight from Tier 1 to Tier 3. AP CSA and Applied Machine Learning teach different fundamentals and neither replaces the other; students may take both, in either order.

Tier 3 — the core advanced course

Recommended

Data Structures and Algorithms Built in Unity with C# 1 semester

  • Requires: any Tier 1 or Tier 2 course
  • Goes beyond the data structures in AP into more advanced design
  • Board games make abstract structures tangible before students code them
  • Aligned with a 2nd or 3rd year college CS course
  • Strongly recommended before the capstone

Capstone

Recommended

Software Development Studio (K)1 semester

  • Requires: two semesters of programming coursework, or instructor permission
  • Ship one large project as a team over a full semester
  • Pick up new tools, languages, and roles as the project demands
  • Service-based work; earns Ke Kilohana credit

Advanced Projects1 semester

  • Requires: Software Development Studio (K)
  • Set your own milestones and build something you own
  • Extend a studio project or start a passion project
  • Portfolio-worthy work for college and internship applications

Software Development Studio (K) → Advanced Projects

Minimum recommended pathway

  • Intro to Programming → Data Structures and Algorithms → Software Development Studio (K) (3 semesters)

Other common pathways

  • Starting junior year: Intro to Programming + Data Structures and Algorithms, then Software Development Studio (K) + Advanced Projects (4)
  • Data focus, no AP: Intro to Programming + Applied Machine Learning + Data Structures and Algorithms + Software Development Studio (K) (4)
  • Security only: AP Cybersecurity (2, complete on its own)
  • Security plus programming: AP Cybersecurity + Intro to Programming + Data Structures and Algorithms + Software Development Studio (K) (5)

Reaching the 7-semester distinction

  • AP CSP + AP CSA + Data Structures and Algorithms + Software Development Studio (K) + Advanced Projects (2+2+1+1+1)
  • AP Cybersecurity + AP CSP + Applied Machine Learning + Data Structures and Algorithms + Software Development Studio (K) (2+2+1+1+1)
  • Intro to Programming + AP Cybersecurity + Applied Machine Learning + Data Structures and Algorithms + Software Development Studio (K) + Advanced Projects (1+2+1+1+1+1)
  • Students aiming for the distinction should start by sophomore year. A junior start requires two computer science courses each year.

Choosing an entry point

  • Intro to Programming — creative, visual, collaborative; the fastest route to Tier 3.
  • AP CSP — broad foundations across programming, data, systems, and impact.
  • AP Cybersecurity — networks and security; standalone, with no programming background assumed.
